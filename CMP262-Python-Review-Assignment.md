## Part 1 – Output and Variables

Create a program that stores and displays:

- Your name
- Your major
- Your favorite number
- One reason you are interested in Data Science

Use variables and `print()` statements.

**Points: 15**

## Part 2 – User Input

Ask the user to enter:

- Their name
- Their age
- Their favorite programming language

Display a short message using the information entered by the user.

**Points: 15**

## Part 3 – Calculations

Ask the user to enter three numbers.

Display:

- The sum
- The average
- The largest value
- The smallest value

**Points: 20**

## Part 4 – Decision Making

Ask the user to enter a numeric grade.

Display the corresponding letter grade using `if`, `elif`, and `else`.

Use the following ranges:

- 90–100: A
- 80–89: B
- 70–79: C
- 60–69: D
- Below 60: F

**Points: 20**

## Part 5 – Loops

Use a loop to display the numbers from 1 through 10.

Then create another loop that displays only the even numbers from 1 through 20.

**Points: 15**

`calculate_average()`

2. Calculate the average.
3. Return the result.
4. Call the function and display the returned average.
