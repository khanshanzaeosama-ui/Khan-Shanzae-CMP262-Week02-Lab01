# CMP 262 – Data Science Programming

## Week 2 – Lab 1: Python Review

Welcome to **CMP 262 – Data Science Programming**.

This lab reviews the core Python programming concepts that you will use throughout the course while working in **Jupyter Notebook inside Visual Studio Code**.

## Lab Goal

By completing this lab, you will practice:

- Variables and output
- User input
- Calculations
- `if`, `elif`, and `else` statements
- Loops
- Functions
- Running Python code in a Jupyter Notebook

## Getting Started

1. Create your own repository from this starter repository using **Use this template**.
2. Name your repository:

   `LastName-FirstName-CMP262-Week02-Lab01`

3. Clone **your own repository** to your computer.
4. Open the cloned repository in **Visual Studio Code**.
5. Open `PythonReview.ipynb`.
6. Select the correct Python kernel if prompted.
7. Read the full directions in `CMP262-Python-Review-Assignment.md`.
8. Complete each section of the lab in the notebook.
9. Add a Markdown heading before each required part.
10. Run every notebook cell and make sure there are no errors.
11. Save your work.
12. Commit and push your completed work to GitHub.

> **Important:** Clone your own newly created repository — not the instructor starter repository.
